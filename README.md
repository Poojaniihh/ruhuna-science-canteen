# Canteen Management System 🍽️

A web-based Canteen Management System developed as a university group assignment using HTML, CSS, and Java.

## Technologies Used
- HTML
- CSS
- Java

## Project Description
The Canteen Management System aims to simplify daily canteen operations by providing an easy way to manage food items, customer orders, and other canteen activities.

## Main Features
- User Management
- Food Item Management
- Food Ordering
- Order Management
- Admin Management

## Project Status
🚧 Currently under development.

## Purpose
This project is developed for educational purposes as part of a university group assignment.
